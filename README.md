# VOXD

Local-first AI voice dictation. Hold a key, speak, and VOXD transcribes your
words locally with Whisper and types them into any application.

- **Local-first** — audio never leaves your machine (unless you opt in).
- **Linux (Wayland) + Windows** support (macOS planned).
- **System tray** app with live status (Idle / Recording / Transcribing / Typing).

Full documentation is being built out in `README.md`. See `CHANGELOG.md` and
`CONTRIBUTING.md`.
